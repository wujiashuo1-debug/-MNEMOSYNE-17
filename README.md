# MNEMOSYNE-17 / 网站记得你

一款纯前端、非线性的悬疑心理恐怖网页游戏。玩家进入一套声称于 2004 年停止维护的研究机构内网，通过网页快照、人员档案、门禁日志、监听录音、照片差异、七日监控与底层文件序列，调查“记忆迁移实验”的真实用途——以及这些旧档案是否真的比玩家更早存在。

所有人物、机构、记录和实验均为虚构。

## 游戏内容

- 三名可选角色，各自拥有不同的私人目标、错误记忆和结局倾向
- 可自由探索的复古桌面与多窗口内部网络；主要调查工具不规定固定顺序
- 七段可任意挑选的“日常侵蚀”监控片段，异常需要结合画面和机器描述判断
- 需要修改地址参数、检查并覆盖 CSS 变量的网页篡改关卡
- 关键词检索、跨设备时钟校正、空间音频重建、照片差异取证与文件分配审计
- 线索不是一次性答案：关键推论需要从多份互相矛盾的记录中建立
- 两层推理板：先建立案情，再用底层证据反证自己的第一次结局
- 玩家可以按正常流程进入二周目，也可以提前闯入审计层并绕过预定结局
- 道德抉择、角色命运、破局结局与永久残留的通关后异变
- 隐藏成就和额外剧情片段
- 本地存档，不依赖服务器
- 移动端适配与低惊吓模式

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 部署到 GitHub Pages

项目已包含 `.github/workflows/pages.yml`，支持项目仓库的子路径，不需要手动修改资源地址。

1. 将代码推送到 GitHub 仓库的 `main` 分支。
2. 打开仓库的 **Settings → Pages**。
3. 将 **Source** 设置为 **GitHub Actions**。
4. 工作流会生成静态站点并部署。

在本地验证 GitHub Pages 静态导出：

```bash
GITHUB_REPOSITORY=你的用户名/仓库名 npm run build:github
```

生成结果位于 `out/`。

## 操作提示

- 游戏鼓励像使用真实旧网站一样操作地址栏、搜索框和残留开发工具。
- 部分声音线索需要耳机；所有核心推理仍有视觉记录可供复核。
- 顶部菜单可将“惊吓”从 `MAX` 切换为 `LOW`。
- 浏览器存储用于保存调查进度、笔记、成就和选择；清除站点数据会重置存档。
